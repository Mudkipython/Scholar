# Private journal ranking data

Put licensed/private JCR or CAS ranking data here when deploying privately.

Supported filenames:

- `private_journal_rankings.csv`
- `private_journal_rankings.xlsx`
- `private_journal_rankings.xls`

You can also set `JOURNAL_RANKINGS_PATH` to point to a file elsewhere.

Do not commit licensed JCR/CAS data to a public repository. The `.gitignore` file excludes the supported private ranking filenames.
